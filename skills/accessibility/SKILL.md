# Accessibility

Inspect the affected interface and test the actual interaction path. Prefer native HTML semantics before ARIA. Check keyboard reachability, focus order and visibility, accessible names, form errors, contrast, zoom, and responsive text where relevant.

Link each finding to user impact and a specific fix. Use automated checks to catch detectable issues, then manually verify interactions they cannot prove. Recheck the changed flow and state clearly which assistive technology or browser combinations were not tested.
